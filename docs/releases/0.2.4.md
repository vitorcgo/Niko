# Niko 0.2.4: Linux funcionando, backup corrigido e tarefas pendentes no Journal

Uma versão de correções: o Niko instalado no Linux passa a abrir, o backup volta a ser salvo e restaurado, e a ilha recolhe ao clicar fora. No Journal, o que ficou para trás nos dias anteriores pode ser trazido para hoje.

## Novidades

- No Journal, as tarefas pendentes de dias anteriores aparecem no dia de hoje, com Trazer todas ou uma por uma. Em qualquer dia, o menu da tarefa tem Trazer para hoje. A tarefa mantém o horário e o aviso permite desfazer.

## Correções

- No Linux, o app instalado abria numa tela branca dizendo que não conseguiu iniciar o serviço local. A interface procurava o serviço só pelo endereço usado no Windows.
- Exportar o backup, o CSV de Finanças, o calendário, uma conversa ou o visual salva o arquivo na pasta Downloads e mostra onde ele ficou. No app instalado o arquivo podia não ser salvo.
- Um backup com uma área danificada restaura as outras e mostra qual ficou de fora, em vez de recusar o arquivo inteiro. Se o backup automático antes de restaurar ou apagar tudo não puder ser salvo, nada é alterado.
- A ilha aberta recolhe ao clicar fora dela no app instalado do Windows.
- As opções Esconder ilha e dock em tela cheia e Apps que sempre escondem a ilha passam a funcionar no Windows. Antes elas eram salvas, mas não tinham efeito.
- No AppImage do Linux, a status line do Claude Code parava de funcionar toda vez que o Niko era aberto de novo.

## Melhorias

- No Linux, os atalhos mostram a tecla Super, e as opções que o Linux ainda não suporta ficam escondidas, com um aviso.

## Antes de instalar

- No Windows, use o instalador .exe. O .msi fica só para quem já instalou por ele. Quem já tem o Niko recebe a atualização pelo próprio app.
- No Linux, use o .deb no Ubuntu, o .rpm no Fedora ou o AppImage em outras distribuições. Quem instalou a 0.2.3 no Linux precisa baixar esta versão à mão, porque a 0.2.3 não chegava a abrir.
- Um aviso de aplicativo não reconhecido pelo SmartScreen não é o mesmo que uma detecção de ameaça pelo Defender. Mantenha o antivírus ativo e baixe somente das releases oficiais.
