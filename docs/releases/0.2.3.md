# Niko 0.2.3: Niko no Linux, apps fixados no dock e OpenCode v2

Uma atualização com a primeira versão do Niko para Linux, três sugestões da comunidade para o dock e o plugin do OpenCode funcionando na v2.

## Novidades

- Fixe apps no dock pelo botão direito em um app aberto. Eles ficam no dock mesmo fechados e abrem com um clique.
- Tamanho do dock de 70% a 120%, pelo menu do dock ou pelos Ajustes. No modo fixo, o espaço reservado na tela acompanha o tamanho.
- Com o dock em vários monitores, escolha se cada dock mostra só as janelas do próprio monitor ou as de todos, pelo menu do dock ou pelos Ajustes.
- Escolha se a música tocando aparece na ilha fechada, pelo botão de olho na aba Mídia ou pelos Ajustes da ilha. A aba Mídia continua funcionando.
- Primeira versão do Niko para Linux (Fedora e Ubuntu com GNOME), a partir da contribuição do PR #11, com pacotes .deb, .rpm e AppImage. É uma versão de teste: alguns recursos do Windows ainda não existem no Linux (veja o README-linux.md).

## Melhorias

- Cada versão na página de novidades vira uma gaveta, com a quantidade de mudanças, e a versão atual abre direto pelo aviso de novidades.
- O cartão do criador fica no topo da página de Atualização.
- Na ilha compacta, o personagem só se mexe quando está pensando ou escrevendo.
- Perguntas longas do Claude Code na ilha rolam sem esconder os botões de responder.
- Tudo o que depende do sistema foi reorganizado num só lugar, com verificação automática no Windows e no Linux a cada mudança.

## Correções

- O plugin do OpenCode funciona no OpenCode v2 e continua funcionando na v1. Quem já instalou vê a opção de atualizar na engrenagem da aba Código.
- O AtalhoTouch aparecia, piscava e sumia ao ser ligado no app instalado. Uma janela relia dados antigos logo depois de outra salvar e desfazia a mudança.
- O instalador do Windows podia dar erro ao gravar arquivos e deixar a versão antiga, pedindo para atualizar de novo. Agora ele fecha antes o que o Niko deixou rodando, inclusive a status line do Claude Code.

## Antes de instalar

- No Windows, use o instalador .exe. O .msi fica só para quem já instalou por ele: instalar os dois deixa duas cópias do Niko no computador. Quem já tem o Niko recebe a atualização pelo próprio app.
- No Linux, use o .deb no Ubuntu, o .rpm no Fedora ou o AppImage em outras distribuições. O Node já vem dentro do pacote. No Linux a atualização ainda é manual: baixe o pacote novo a cada versão.
- Um aviso de aplicativo não reconhecido pelo SmartScreen não é o mesmo que uma detecção de ameaça pelo Defender. Mantenha o antivírus ativo e baixe somente das releases oficiais.
